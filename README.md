## CN2 GIA 到底好在哪：先看线路原理

CN2 GIA 是中国电信骨干网里的高端线路，去程和回程都走电信直连专线（AS4809），带独立 QoS 通道。国内 VPS 最常见的是 AS4134（ChinaNet/163 网），容量大、最便宜，但晚高峰拥堵时丢包率能到 30% 以上——这也是为什么网站放普通美国 VPS 上，国内用户晚上打开会卡。

中间还有一档 CN2 GT（Global Transit），设计初衷是缓解拥堵，但多个测评指出 2019 年之后它的晚高峰表现已经和 163 网相差不大。真正拉开差距的是 GIA：官方口径里，CN2 GIA 的 IP 中转单价能到每兆 120 美元，1Gbps 满带宽跑一个月账单是十万美元量级。这个成本直接解释了两件事——真正便宜的 CN2 GIA VPS 总是限量，而搬瓦工这个系列的价格为什么压不下来。

搬瓦工的 CN2 GIA-E（官方称 ECOMMERCE 电商级，部分资料也写作 Enhanced 增强版）在这个基础上又做了两点增强：带宽从 1Gbps 起跳拉到 2.5Gbps（最高 10Gbps），并且三网回程各有专线——电信走 CN2 GIA（AS4809），移动走 CMIN2（AS58807），联通走 China Unicom Premium（AS10099）。洛杉矶 DC6 和 DC9 机房都已经接入 CMIN2，移动用户选这两个机房后回程自动走精品线路，无需任何设置。电信、联通、移动用户都能吃到优化，这一点比只优化电信回程的方案实在。

## 下单前要知道的限制

这一节是很多测评文章一笔带过、但会实际影响使用的东西。

**DDoS 防御很弱。** CN2 GIA 网络容量有限，官方写明被攻击时会“被迫走 IP 空路由”——也就是被攻击的 IP 直接黑洞掉。如果你跑的业务容易被盯上，163 骨干网这类“扛打”线路反而更合适，GIA 不适合当抗攻击方案。

**完全自助服务。** 搬瓦工是 self-managed，出了技术问题自己解决，没有托管支持。有面板、快照、备份和 API，但期望“工单有人帮配环境”的会失望。

**带宽不分级。** 香港、东京系列加钱只能买到更多 CPU、内存和流量，带宽始终是 1Gbps / 1.2Gbps。想靠升套餐换更宽出口的话，这条路走不通。

**流量是软上限。** 超过月流量配额会触发额外计费或降速，不会直接断网，具体处理方式以官网当时公示为准。40G 档 0.5TB/月的配额对跑流量的业务偏紧，建议按实际用量留 20%–30% 余量再选档。

## 买前自测和买后测速

下单前可以直接 ping 机房测试 IP 看延迟和丢包：DC6 测试 IP 是 104.200.20.165，DC9 是 23.105.218.1，香港机房测试 IP 在 93.179.124.x 段。配合 ping.chinaz.com 能看到全国各省的延迟分布，比单点测试更有参考价值。想确认移动回程是否真走 CMIN2，可以用 NextTrace 或 BestTrace 跑一次 traceroute，回程出现 AS58807 就是精品线路。

买之后的测速也简单：在 VPS 上跑 `wget -qO- bench.sh | bash` 可以测 CPU、磁盘 IO 和各地下载速度，再用 iperf3 或持续 ping 观察晚高峰表现。记住一个细节：VPS 的上传速度就是你本地的下载速度，看 speedtest 的“上传”栏即可。
